
# Takeout Platform — Full-Stack Software Testing Project

A full-stack food delivery platform developed as a software engineering and testing project. The system supports multiple user roles, including customers, merchants, riders, and platform administrators.

## Project Overview

This project was developed to practice full-stack web application development and software testing. The backend is implemented with ASP.NET Core, while the frontend is built with Vue 3 and Vite.

The system covers common food-delivery workflows such as ordering, merchant management, rider delivery, and platform administration.

## Key Features

* Customer-side food browsing and ordering
* Merchant-side store, dish, and order management
* Rider-side delivery workflow
* Platform administration functions
* REST-style backend APIs
* Frontend and backend integration
* Relational database access with Entity Framework Core
* Automated testing support
